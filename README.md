# Computer_Forensic_M4

🔥 Proyecto educativo y ofensivo-defensivo de **informática forense** y **ciberseguridad**, creado por M4. Este repositorio reúne **herramientas forenses de código abierto**, entornos portables, libros y recursos digitales para formar a investigadores, analistas y entusiastas del hacking ético.

> “El que domina los rastros, domina la verdad.” – M4

---

## 🧱 ¿Qué incluye este repositorio?

- 🛠️ Herramientas forenses para análisis de discos, RAM, logs, tráfico de red y malware.
- 🧰 Scripts automáticos de instalación en Linux.
- 📚 Libros introductorios y avanzados de ciberseguridad y análisis forense.
- 🧪 Entornos virtualizados y contenedores listos para pruebas.
- 👨‍💻 Recursos para red team, blue team y análisis OSINT.

---

## 📘 TEMARIO / ÍNDICE DE CONTENIDO

### 🧬 Módulo 1 – Introducción a la Informática Forense
- ¿Qué es la informática forense?
- Tipos de evidencia digital
- Ciclo de vida de un análisis forense

### 💾 Módulo 2 – Herramientas Forenses de Disco y Archivo
- Sleuthkit y Autopsy
- Foremost, Scalpel, Photorec
- Hashing y verificación de integridad

### 🧠 Módulo 3 – Análisis de Memoria RAM
- Volatility y Rekall
- Dumps de memoria y extracción de procesos

### 🌐 Módulo 4 – Tráfico de red y OSINT
- Wireshark y NetworkMiner
- Técnicas de fingerprinting
- OSINT: búsqueda e investigación con fuentes abiertas

### 🛡️ Módulo 5 – Análisis de malware y reversa
- PEStudio, Capa, YARA
- Binwalk y análisis binario
- Introducción a Ghidra

### 📚 Recursos Extra
- Manuales para Red Team y Blue Team
- Libros PDF recomendados (ver carpeta `resources/`)
- Scripts útiles de monitoreo y análisis
